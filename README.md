# 설문 집계기

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)를 보여주는 `index.html` 한 파일입니다.
외부 라이브러리·글꼴·분석 도구를 쓰지 않으며, 붙여넣은 데이터는 브라우저 밖으로 보내거나 저장하지 않습니다(CSP로 외부 통신도 차단).

- 사용: `index.html`을 브라우저로 열기 (GitHub Pages로 배포 가능, `.nojekyll` 포함)
- 시험: `node --test` (Node 18+, 의존성 없음)
- 집계 기준과 설계: [PLAN.md](PLAN.md)
