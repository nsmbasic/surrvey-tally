# 10×10 오목

한 기기에서 두 사람이 번갈아 두거나 컴퓨터와 두는 10×10 오목 / 3목 게임입니다. `index.html` 한 파일이며 외부 라이브러리·글꼴·분석 도구, 네트워크 통신이 없습니다.

- 규칙: 흑 선공. 가로·세로·대각선으로 목표 개수(오목 5, 3목 3) 이상을 먼저 이으면 승리(6개 이상도 승리). 판이 가득 차면 무승부. 무르기 지원.
- 컴퓨터 상대: 내가 흑(선공)·백(후공) 선택. 규칙 기반 AI(이길 수 있으면 승리, 상대 승리를 막고, 공격·수비 점수가 높은 칸을 선택)이며 같은 판에서는 같은 수를 둡니다.
- 사용: `index.html`을 브라우저로 열기 (GitHub Pages 배포용 `.nojekyll` 포함)
- 시험: `node --test` (Node 18+, 의존성 없음). 게임 로직은 `index.html`의 `<script id="game-logic">` 블록이며 화면과 분리되어 있습니다.
